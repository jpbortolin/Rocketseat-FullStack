# 🚀 Formação Full-Stack | Rocketseat

Repositório dedicado aos meus estudos na formação **Full-Stack da Rocketseat**. Aqui vou reunir exercícios, anotações, desafios e projetos desenvolvidos ao longo do curso, registrando minha evolução no desenvolvimento web.

O percurso vai dos fundamentos de HTML, CSS e JavaScript à construção de aplicações completas com React, Node.js, bancos de dados, autenticação, testes e deploy.

## 🎯 Objetivos

- Consolidar os fundamentos do desenvolvimento web.
- Construir interfaces responsivas e interativas.
- Desenvolver APIs REST e integrar o front-end ao back-end.
- Trabalhar com bancos de dados, containers e testes automatizados.
- Praticar versionamento de código e documentar os aprendizados.
- Desenvolver autonomia na resolução de problemas e na construção de projetos.

## 🛠️ Tecnologias e ferramentas da formação

| Área | Tecnologias e conceitos |
| --- | --- |
| Fundamentos web | HTML, CSS, JavaScript e TypeScript |
| Front-end | React, React Router, React Hook Form e Tailwind CSS |
| Back-end | Node.js, Express, APIs REST e middlewares |
| Banco de dados | SQL, PostgreSQL, SQLite, Knex.js e Prisma ORM |
| Validação e segurança | Zod, JWT, autenticação e autorização |
| Testes | Jest e testes end-to-end |
| Infraestrutura | Docker, Docker Compose e deploy |
| Versionamento | Git e GitHub |
| Apoio ao desenvolvimento | Terminal, DevTools e IA aplicada ao aprendizado |

> As tecnologias acima fazem parte do conteúdo previsto no curso e serão praticadas ao longo dos estudos.

## 📚 Trilha de estudos

Checklist para acompanhar a conclusão de cada nível:

- [X] **Nível 1 — Fundamentos da Programação Web e Setup**  
  Hardware, software, sistemas operacionais, internet, front-end, back-end e configuração do ambiente de desenvolvimento.

- [ ] **Nível 2 — Git e GitHub**  
  Versionamento de código, configuração do Git, repositórios, commits, histórico de versões e colaboração pelo GitHub.

- [ ] **Nível 3 — Fundamentos do HTML e do CSS**  
  Estrutura e semântica do HTML, atributos, links, listas, imagens, box model, textos, cores e backgrounds.

- [ ] **Nível 4 — Usando Inteligência Artificial no Aprendizado**  
  Uso de IA para esclarecer dúvidas, investigar bugs, criar desafios e revisar o aprendizado com autonomia.

- [ ] **Nível 5 — Avançando no HTML e CSS**  
  Position, variáveis, pseudo-classes, Flexbox, Grid, formulários, funções CSS, responsividade, animações e transições.

- [ ] **Nível 6 — JavaScript**  
  Fundamentos, funções, escopo, DOM, eventos, expressões regulares, repetições, datas, classes, imutabilidade, módulos, assincronismo, APIs e bundlers.

- [ ] **Nível 7 — TypeScript**  
  Tipagem estática, interfaces e tipos avançados para organizar e tornar o código mais seguro.

- [ ] **Nível 8 — Iniciando no Node.js**  
  Servidores com o módulo HTTP, requisições, middlewares, fundamentos de APIs e manipulação de dados.

- [ ] **Nível 9 — API REST com Node.js**  
  Express, rotas, tratamento de erros, validação com Zod, bancos relacionais, SQL, Knex.js, migrações e transações.

- [ ] **Nível 10 — Node.js com Containers**  
  Docker, Docker Compose, volumes, Prisma, JWT, autenticação, autorização, Jest, testes end-to-end, deploy e gerenciamento de dependências.

- [ ] **Nível 11 — Bônus: API do Refund 2.0**  
  API para um sistema de reembolso, com autenticação, autorização, upload e validação de arquivos.

- [ ] **Nível 12 — Iniciando no React**  
  Componentes reutilizáveis, propriedades, estados e manipulação de eventos.

- [ ] **Nível 13 — Avançando no React**  
  React Router, formulários, React Hook Form, Tailwind CSS, integração com APIs, contextos, paginação, upload e deploy do front-end.

- [ ] **Nível 14 — HelpDesk**  
  Desafio de construção de uma aplicação completa de gerenciamento de chamados, com front-end, back-end e painéis de Administrador, Técnico e Cliente.
