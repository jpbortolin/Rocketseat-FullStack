# Stage 03 - HTML e CSS

## HTML

- HT: Hypertext (Hipertexto)
- M: Markup (Marcação)
- L: Language (Linguagem)

```
HTML é uma linguagem de marcação de hipertexto
```

## O que é o HTML?

Não é uma linguagem de programação, pois não se enquadra nas regras para ser uma *linguagem de programação*, é apenas uma linguagem por conta da sua sintaxe.

- Possui `tags` (marcação);
- Links para outros textos;
- Imagens, Sons e Videos;
- Arquivos com a extensão `.html`.
